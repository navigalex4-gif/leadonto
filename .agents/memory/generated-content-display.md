---
name: Generated content display
description: Shared presentation rules for AI-generated text across EduBharat tools and feeds
---

Rule: generated text shown in the product must be normalized into readable plain text, without exposing Markdown syntax such as heading, bold, or code markers.

Rule: generated lesson and career summaries should offer consistent listen and save actions wherever the content is reusable.

**Why:** raw model formatting makes the product feel unfinished and creates inconsistent reading, speaking, and history experiences.

**How to apply:** use the shared text formatter for display and speech, preserve readable paragraph/list spacing, and keep generated-output actions consistent across tools, feeds, history, and lesson plans.
